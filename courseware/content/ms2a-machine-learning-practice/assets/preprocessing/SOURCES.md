# Sources of the third-party figures in this folder

Every other file here is generated by `tools/figures/s2_data_preprocessing.py`.
The ten below were taken from the internet on 2026-09-15 for the split of
Session 2 into eight teaching lessons; each row records where it came from and
under which licence, so the deck and the website can be redistributed.

Commons SVGs were downloaded as PNG renders through
`https://commons.wikimedia.org/wiki/Special:FilePath/<name>.svg?width=<px>`
and flattened onto white. scikit-learn figures are the documentation's own
gallery images (BSD-3-Clause, © scikit-learn developers).
